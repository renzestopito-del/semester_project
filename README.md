# Semester Project

## Summary
This project is a Flutter Web starter application with Home and Login screens.

## Current Stack
- Dart
- Flutter Web
- REST API (planned)
- PostgreSQL (planned)

## Run Locally
1. Install Flutter and Google Chrome.
2. Open a terminal in the project folder.
3. Run:

```bash
flutter pub get
flutter run -d chrome
```
